# Cartly: Frontend Final Project

An online shopping website built with **HTML, CSS and JavaScript only**. It has landing pages,
sign up / log in, and a shopping dashboard (shop, product details, cart, wishlist, orders, profile).
Everything is saved in the browser with `localStorage`.

## Folders

| Folder | What it is |
|---|---|
| [`cartly-starter/`](cartly-starter/) | **Students start here.** The project brief ([README](cartly-starter/README.md)), designs, images and product data. |
| [`cartly-solution/`](cartly-solution/) | The finished reference website. |
| [`TEACHER-GUIDE.md`](TEACHER-GUIDE.md) | Schedule, marking rubric and common mistakes. |

## Get the starter files

Click the green **Code** button → **Download ZIP**, unzip it, and open the `cartly-starter`
folder in VS Code. Then read [`cartly-starter/README.md`](cartly-starter/README.md).

## Run the solution locally

Open `cartly-solution/index.html` with **Live Server** in VS Code.
(It must run on `http://`, not by double-clicking the file, because it uses `fetch`.)
